# Sysplorer 2026b 远程插件任务状态接口补丁

本补丁针对 2026b `26.8.0.2280`，用于已有远程部署。2026-11-07 实测已通过远端认证，但旧插件返回 `HOST_TASK_STATUS_API_UNSUPPORTED`，在返回模型哈希之前结束 hello。本次不更换 Qt 客户端或模型，不重新安装远程服务，不更换访问凭据。

## 本次修复与验证范围

- 保留原 `IsRunning()` 精确签名的优先级，增加 SDK 明确定义的 `GetRunningThread()` 精确签名适配。非空任务指针一律视为繁忙，不读取对象内存，不推测未知 ABI。没有已知接口仍拒绝任务。
- 即使宿主尚未就绪或接口不支持，hello 也返回插件模型哈希及两项生命周期能力，便于先核对模型；错误响应仍然是失败，不能据此加载或求解。
- 客户端、模型文件、通信协议、访问密钥、端口和防火墙均不改变。更新脚本只备份并替换指定 DLL；不会结束任何进程。
- 已通过接口选择和模型预检测试、隔离真实 2026a 回归；虚拟机 2026b 随后安装本插件，并使用修正后的启动器完成真实连接、加载、翻译、求解、暂停/继续、调参及完整/部分结果下载验收。

## 虚拟机内按顺序操作

1. 将 `BatteryConsole-Server-ApiPatch.zip` 复制到虚拟机，解压到 `C:\Users\dfq\Downloads`。确认 `C:\Users\dfq\Downloads\BatteryConsole-Server-ApiPatch` 直接包含 `Update-ServerPlugin.ps1`、`patch-manifest.json`、`battery_udp_control.dll`、`Diagnose-Server.ps1` 和本说明。
2. 保存工作，关闭目标安装目录下全部 Sysplorer。补丁不会自动关闭程序。
3. 在虚拟机的**管理员 PowerShell** 中执行（若解压位置不同，替换脚本路径）：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File 'C:\Users\dfq\Downloads\BatteryConsole-Server-ApiPatch\Update-ServerPlugin.ps1' -SysplorerHome 'C:\Program Files\MWORKS\Sysplorer 2026b'
```

4. 应输出 `Updated plugin`、新 DLL SHA-256、旧 DLL 备份路径及配置保留提示。新 DLL 哈希见同目录 `patch-manifest.json` 的 `newPluginSha256`。该包只接受已知前版 `9DE7BBE8…` 及指定宿主版本；若拒绝，保留报错并执行下面的诊断，不手动覆盖未知版本。
5. 还需使用修正后的服务器启动器，保留原部署记录和凭据。已有原服务器包的旧启动脚本缺少求解器运行路径，请先解压 `BatteryConsole-Server-LaunchFix.zip`，然后启动：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File 'C:\Users\dfq\Downloads\BatteryConsole-Server-LaunchFix\Start-Sysplorer.ps1' -SysplorerHome 'C:\Program Files\MWORKS\Sysplorer 2026b' -Workspace 'C:\BatteryJobs'
```

6. 等待主窗口完成初始化，再检查监听：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File 'C:\Users\dfq\Desktop\BatteryConsole-Server-win64\Check-Server.ps1' -Port 39001
```

7. 用补丁自带的诊断脚本读取实际 DLL 和接口导出，不读取密钥：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File 'C:\Users\dfq\Downloads\BatteryConsole-Server-ApiPatch\Diagnose-Server.ps1' -SysplorerHome 'C:\Program Files\MWORKS\Sysplorer 2026b' -OutputFile 'C:\Users\dfq\Downloads\BatteryConsole-Server-ApiPatch\server-diagnostic.json'
```

8. 应检查 `taskStatusSupported=True`，且未出现必要动态接口缺失。诊断只表明接口存在，仍须完成下一节的真实模型和业务验收。若失败，只提供报错或 `server-diagnostic.json`；不提供 `remote.ini` 和密钥文件。

不要运行 `Install-Server.ps1`，也不要把旧服务器包里的 DLL 再复制回安装目录。退出并重新启动 Sysplorer 才能使新 DLL 生效。需要回退时，先保存并关闭目标 Sysplorer，再从脚本打印的备份位置恢复旧 DLL；配置与凭据不变。

满足全部条件后才使用已有客户端测试连接、加载、翻译、开始、暂停/继续、停止、调参和结果下载：
