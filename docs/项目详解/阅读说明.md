# 项目详解阅读说明

从 `index.html` 打开图文入口，按 01、02、03 的顺序阅读。三份 HTML 内嵌全部图片和样式，可以离线打开或单独复制。浏览器打印时会隐藏侧边目录，并使用专门的打印样式。

同名 Markdown 是可维护的文字版本，已包含实际源码摘录和行号；阅读其中图片时需同时保留 assets 文件夹。源码摘录定位号是文档添加的，不属于原代码。路径以仓库根目录为基准，行号对应 2026-11-08 当前工作树。

图示依据当前源码整理。客户端启动图来自 R5 ZIP 启动检查；连接设置图来自历史模拟协议测试；结果页截图来自历史回环 TCP 实机，只说明布局。这些区别也在图旁标注，历史截图不充当 R5 虚拟机验收证据。实际结果对照图来自 R5 已核验的本机和远程 CSV。

当前模型来源为客户端内置资源并上传，插件通过 SDK 从收到的文本建立模型。文档不运行仿真、不修改应用代码、安装目录或安全策略，也不包含真实访问密钥、发现令牌、宿主程序或完整模型文本。

文档生成入口为 `tools/documentation/build_project_docs.py`，写作模板位于同目录 templates；该工具提取当前源码并生成 SVG、Markdown 和 HTML。浏览器排版检查入口为 `tools/documentation/verify_project_docs.cjs`，需要可用的 Playwright 包和 Windows Edge，其浏览器配置及验证截图写在当前树的 logs/project-docs-20261108。

本阅读包依据 R5 的现有测试证据，保留远程一次连接超时、退出停止时序及尚未重新验收的路径，不宣称所有版本或所有场景都已通过。源码摘录文件哈希及图片来源见 manifest.json。
