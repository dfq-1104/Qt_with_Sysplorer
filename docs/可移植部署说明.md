# 电池仿真：按顺序操作

本包发布标识：20261108-embedded-model-r5。模型已编入客户端 EXE，运行时不读取外部 `.mo` 文件。双击 `Start-Client.cmd` 会先校验内置模型，再显示原界面；不自动连接或启动 Sysplorer。本机普通双击完整流程、最终 EXE 到实际虚拟机的远程求解均已通过，详情及边界见《验证记录.md》。

先选路线：只用当前电脑计算，执行路线 A；另一台电脑计算，先在服务器执行 B1，再在客户端执行 B2。两条路线用同一个客户端，界面布局相同。

## 路线 A：只在本机运行

**在哪台电脑：安装了 Sysplorer 2026a/2026b 并有有效许可的本机。** 不需要服务器包，不需要 IP、端口或访问凭据。

1. 确认本机已安装并授权 Sysplorer。仅首次安装插件或需要更新插件时，先保存工作并退出目标安装的所有窗口；日常运行不需要先退出已就绪的宿主。脚本不会替你关闭程序。当前电脑的正确安装目录是 `C:\Program Files\MWORKS\Sysplorer 2026a`。
2. 将客户端 ZIP **完整解压到一个新目录**，不要覆盖正在运行的旧客户端，不要在压缩包里点击 EXE。文件夹里应有 `Start-Client.cmd`、`battery_console_ui.exe`、Qt DLL 和配置脚本；不需要也不提供外部模型文件夹。
3. 双击 `Check-Model.cmd`。应显示“模型自检通过”和发布标识，并给出诊断 JSON 位置。它不启动或连接 Sysplorer。若失败，保留 `model-check-result.txt` 和 JSON，停止后续步骤；不要改文件编码或重新安装宿主来猜测修复。
4. 双击 `Start-Client.cmd`。成功画面是原来的电池界面；此时不自动启动或连接 Sysplorer。
5. 点击右上角“连接设置”，选“本机”，再点“保存并连接”。首次操作会检查插件，缺少或需要更新时出现系统管理员授权提示，请允许。多个安装时选择正确目录；浏览选择时选该目录的 `Bin64\mworks.exe`。若提示目标实例仍在运行，保存并手动关闭目标 Sysplorer，再重新连接。
6. 配置成功后，客户端会按需连接或启动所选 Sysplorer。等待初始化结束，应显示“已连接”。配置和任务目录在本机生成，不需要开发机路径或盘符映射。
7. 点击“加载模型”，等待加载完成；设置充放电参数并保存，再点击“翻译模型”，等待准备完成；点击“开始仿真”。也可以直接点击翻译或开始，由程序补齐上传、加载和准备。
8. 仿真完成后，在结果曲线页查看结果，点击回放；运行中可用原来的调参入口。退出前先停止任务并等停止确认。

**失败后的下一步：** 若显示未就绪，请等待后重新连接；若显示繁忙，请先完成你已启动的任务；若模型失败，展开阶段日志，将错误文字、诊断 JSON 和任务目录的 `client.log` 一起保留。历史有效结果不会因本次失败被删除。不要反复更新安装目录来绕过兼容性检查。

## 路线 B1：另一台电脑计算——先配置服务器

**在哪台电脑：真正运行 Sysplorer 的服务器电脑，例如虚拟机。该电脑必须已有有效 Sysplorer 许可、编译器和求解器。** 首次做一次，下次日常使用从第 5 步开始。

1. 保存工作，关闭该安装目录下所有 Sysplorer。完整解压**服务器 ZIP**到可写目录；不要解压成客户端包，也不要只复制一个 DLL。
2. 双击 `Setup-Server.cmd`。按提示选择实际 Sysplorer 安装目录，并允许必要的管理员授权。虚拟机当前是 `C:\Program Files\MWORKS\Sysplorer 2026b`；自定义目录可浏览到 `Bin64\mworks.exe`。
3. 等待配置完成。脚本安装并校验插件，创建英文任务目录，启用远程监听，配置入站防火墙。默认 TCP **39001**；已有有效端口、任务目录和访问凭据会沿用。原来只配置过本机模式也会自动启用远程，不需要编辑 INI。已有有效密钥不会轮换。
4. 完成窗口会显示实际 IPv4、端口和**凭据文件位置**。点击“复制访问凭据”，将该值安全交给客户端使用者；不要发到公共聊天或截图。以后要再次复制，双击 `Server-Info.cmd`。密钥文件只允许当前用户、管理员和系统访问。多个网卡时选择客户端能访问的服务器网卡 IPv4。
5. 双击**原来的 Sysplorer 桌面图标**，等待主窗口初始化。无需特殊启动脚本，无需打开模型，也无需在服务器同时运行 Qt。Sysplorer 必须保持运行。
6. 双击服务器包里的 `Check-Server.cmd`。只有显示 **“可以连接：监听、双向认证、模型上传能力、仿真引擎均已就绪”** 才继续。仅有 `Listening=True` 不算完成；此检查还不代表客户端网络已经可达。
7. 若提示无监听，确认启动的是第 2 步选择的安装，插件已启用，且窗口初始化完成；仍失败时保留错误文字和提示的诊断文件。若提示未就绪或繁忙，等待初始化或结束现有任务后重试。不要重生成密钥。

服务器的 IPv4 示例是 **172.19.15.159**，默认网关 **172.19.0.1** 是网络出口，不能代替服务器地址。虚拟机重启后 IP 可能变化，以配置完成页/服务器网卡的当前 IPv4 为准。

## 路线 B2：另一台电脑计算——再连接 Qt 客户端

**在哪台电脑：显示 Qt 界面的客户端电脑。仅用远程模式时不要求这台电脑安装 Sysplorer。**

1. 将客户端 ZIP 完整解压到新目录，双击 `Check-Model.cmd`，确认模型自检通过。
2. 双击 `Start-Client.cmd`，点击“连接设置”，选择“远程”。
3. 填 B1 显示的服务器 IPv4、端口及“复制访问凭据”得到的**原凭据**。点击“保存并连接”。不要填默认网关，不要把凭据文件路径当密钥填写。
4. 成功时顶部显示远程地址和“已连接”。凭据用当前 Windows 用户的 DPAPI 加密保存在客户端，通常只填一次。换电脑、用户或服务器，或者服务器主动轮换密钥后再填；输入留空会复用旧值。认证失败请完整重填正确值，不需要重装服务器。
5. 点击“加载模型”→设置并保存参数→“翻译模型”→“开始仿真”。结果会下载到客户端，可查看曲线和回放。远程失败不会切换到本机。断线后使用原“重连并核对”，不要重复启动远端任务。

## 模型在哪里

模型文本编入客户端 EXE 的 Qt 资源 `:/models/BatterySim.mo`。这个名称是内存资源地址，不是磁盘上的文件路径。正式客户端忽略外部 `BATTERY_MODEL_FILE` 环境变量，也不回退读取旁边的 `.mo` 文件。

两种模式上传同一份内置文本：本机回环 UDP、远程认证 TCP。插件校验完整性后，在宿主任务目录保存并加载本次收到的模型，再翻译、求解。服务器仍会使用任务文件和求解器文件；“内置”指客户端不再读取外部模型，不代表仿真全程无磁盘文件。

只支持既定的 `BatterySim.SingleRun` 电池接口，最大 1 MiB、合法 UTF-8。任务和结果记录本次文本的 SHA-256。插件不会覆盖用户手工加载的同名模型或未保存修改。更新模型需要重新构建、发布客户端，不需要为模型变更重新构建插件；内置不等于加密或防提取。

## 更新与回退

- 只更新插件：手动保存并关闭目标 Sysplorer；使用下方附录的 `Update-Plugin.ps1`。该入口不改配置、凭据、端口和防火墙。首次配置/本机转服务器用 `Setup-Server.cmd`，不要混用。
- 更新客户端：关闭旧 Qt，将新 ZIP 解压到新目录，从新目录启动。保留现有用户配置，勿混搭新旧 EXE/DLL。模型自检中的发布标识应与清单一致。
- 更新脚本备份旧 DLL 到包目录 `versions\旧哈希.dll`，校验后复制；失败尝试恢复旧 DLL。回退时停止任务并关闭两端程序，恢复备份 DLL并使用对应旧客户端。本机转服务器前的配置备份在安装插件目录 `remote.ini.before-server-setup.bak`，含凭据，勿公开。日常自行妥善备份配置。

## 旧版外部模型故障与新版检查

此前 R3/R4 普通窗口读取外部模型时获得 18,096 字节，测试上下文则是合法的 14,000 字节。R5 按已确认的模型分发方式，将项目模型编入 EXE，不再走该外部文件读取链路；没有停用、修改或配置天喻。

新版自检诊断应显示 `source=embedded-resource`、路径 `:/models/BatterySim.mo`、长度 14,000 字节，SHA-256 为 `e03bd3634004ca82bb190521c214ec5fae25713120db83caf016aeac8b7472cd`。如界面仍显示外部模型路径，请先核对是否打开了旧 EXE。若内置模型校验失败，保留诊断并完整解压新包，不要转换编码或停用文件保护软件。

## 远程没有监听时

先双击 Check-Server.cmd，阅读方括号错误代码。PLUGIN_NOT_LOADED 表示 Sysplorer 已运行但没加载插件；此时 IP 和密钥还没进入验证阶段。双击 Diagnose-Plugin.cmd 可以检查缺失 DLL/导出，无需重新安装。CONFIG_VIEW_MISMATCH 表示磁盘与宿主读到的启用状态不一致；PORT_NOT_LISTENING 会保留实际状态及监听错误。

已确认的 2026b 加载问题是 SetWorkPath 接口增加了上下文参数，当前插件已移除该静态导入，使用每任务代码/结果/求解器/进程目录隔离，不改写全局 WorkPath。仅更新此插件时，保存并关闭目标 Sysplorer，右键 Update-ServerPlugin.cmd 选择「以管理员身份运行」，随后从原桌面图标启动并重新检查。原配置、密钥及端口保留，不必重复首次配置。

## 故障附录：仅在需要时使用命令

在对应解压目录空白处打开 PowerShell。普通用户双击入口已覆盖日常操作；安装目录受保护时使用管理员 PowerShell。以下路径按实际安装替换。

指定本机安装（客户端电脑）：
```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Setup-Local.ps1 -SysplorerHome 'C:\Program Files\MWORKS\Sysplorer 2026a'
```
仅更新插件（运行 Sysplorer 的电脑，先关闭它）：
```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Update-Plugin.ps1 -SysplorerHome 'C:\Program Files\MWORKS\Sysplorer 2026b'
```
首次自定义服务器端口、任务目录和允许的客户端网段（服务器电脑）：
```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Setup-Server.ps1 -SysplorerHome 'C:\Program Files\MWORKS\Sysplorer 2026b' -Workspace 'C:\BatteryJobs' -Port 39001 -AllowedClientAddress 'LocalSubnet'
```
已有部署会优先保留有效端口和任务目录。改已有端口/目录时须关闭宿主、备份配置，由管理员明确修改后再配置和检查，并同步客户端；不要删除密钥来重新安装。默认防火墙只允许 Domain/Private、本地子网，公共网络不会放行。跨子网需管理员指定准确客户端 IP/CIDR 并核对已有规则，不应放开所有网络。

求解器异常退出时先检查配套插件、许可和编译器，保留宿主消息和任务日志；不要随意复制 DLL 或改全局 PATH。认证并非传输加密，跨不可信网络应使用受控 VPN。

**已知边界：** 关闭 Qt 窗口时停止任务仍是尽力处理，尚有不稳定情况。请先点击停止，确认任务停止后退出。远程实测记录过一次连接/认证超时，随后显式重试完成求解；出现同类问题时先确认服务器 READY，再使用原重连入口，不默认重置密钥或回退本机。远程实际回放/调参未在 R5 普通双击路径重新验收，不与既往版本的测试混算。
