# 电池仿真两端部署说明

本轮为模型上传改造候选版本。实际验收范围以随包《验证记录.md》为准，未通过的宿主版本不能按已验证版本使用。

## 1. 先确认软件与许可

两端均为 Windows x64。运行仿真的电脑必须已合法安装并授权 Sysplorer 2026a 或 2026b，包括模型翻译所需编译器、求解器及运行库。压缩包不包含 Sysplorer、许可或 SDK；目标电脑不需要安装 Qt 或开发工具。仅使用远程连接的客户端电脑不需要安装 Sysplorer。

客户端是模型文本来源：`models/BatterySim.mo`。本机通过回环 UDP、远程通过认证 TCP 上传同一份 UTF-8 文件。插件接收、校验、加载、翻译、求解后返回数据。插件不再内置仿真模型。此次固定支持 `BatterySim.SingleRun` 和既有电池参数、实时调参、结果接口，不能把任意 Modelica 模型放进去直接使用。

## 2. 先部署服务器电脑

1. 将服务器 ZIP 完整解压到可写目录。不要在 ZIP 内直接启动，不要将客户端包当服务器包。
2. 先正常打开 Sysplorer 确认许可可用，保存工作后手动关闭该安装目录的全部 Sysplorer 实例。安装脚本不会结束程序。
3. 双击 `Setup-Server.cmd`，按系统提示允许管理员提权。检测到多个 2026a/2026b 安装时，必须选择实际使用的安装目录。自定义安装位置可在 PowerShell 中运行：

   ```powershell
   powershell.exe -NoProfile -ExecutionPolicy Bypass -File '.\Setup-Server.ps1' -SysplorerHome 'D:\MWORKS\Sysplorer 2026a'
   ```

4. 首次配置安装配套 `battery_udp_control.dll`，创建英文任务目录 `C:\BatteryConsoleData\jobs`，授予当前桌面用户写入权限，并创建 TCP 39001 的入站规则。默认允许域/专用网络的本地子网访问。
5. 首次配置在 `Sysplorer安装目录\Bin64\addins\BatteryUdpControl\remote.ini` 生成 `AccessKey`。用有权限的编辑器读取此字段，单独安全地交给客户端使用者。不要把它放进聊天、截图或公共日志；本包不会附带开发者的密钥。
6. 已有部署再次配置或仅更新插件，会保留整个现有 `remote.ini`，包括端口、地址、任务目录和访问凭据。若此电脑先配置了本机模式，已有 `Enabled=false`，服务器配置会明确拒绝静默改写；请在管理员编辑器中将 `Enabled=true`、设置至少 32 字符随机 `AccessKey` 后重试，或在备份原文件后按首次服务器配置部署。
7. 配置完成后，直接双击原来的 Sysplorer 桌面图标，等待初始化完成。插件会自动加载并监听，不需要打开模型，不需要同时运行 Qt，也不需要特殊 PATH 启动脚本。Sysplorer 必须保持运行；本次不提供后台服务或开机自启。
8. 在服务器包目录打开 PowerShell 检查：

   ```powershell
   powershell.exe -NoProfile -ExecutionPolicy Bypass -File '.\Check-Server.ps1' -Port 39001
   ```

   预期 `Enabled=True`、`Listening=True`。请以日常启动 Sysplorer 的同一 Windows 用户检查。若使用已有非默认端口，替换上面的端口；没有记录时，先检查 Sysplorer 的插件启用设置中 `Battery UDP Control` 是否启用，启用后重启目标宿主。
9. 在服务器执行 `ipconfig`，记录实际联网适配器的 IPv4 地址，例如 `172.19.15.159`。客户端应连接这个地址。默认网关 `172.19.0.1` 是网络出口；除非专门配置端口转发，否则不是服务器地址。虚拟机 DHCP 地址可能在重启后改变。

## 3. 客户端连接远程服务器

1. 完整解压客户端 ZIP；保留 `models`、Qt DLL、`platforms` 和所有脚本的相对位置。
2. 双击 `Start-Client.cmd`。启动只显示界面，不连接、不启动本机 Sysplorer。
3. 点击“连接设置”，选择远程模式，填写服务器实际 IP、监听端口及服务器 `remote.ini` 的原 `AccessKey`，再点击“保存并连接”。连接失败不会切换为本机模式。
4. 凭据用当前 Windows 用户的 DPAPI 加密保存在该电脑的用户配置中。通常只需填一次；换用户、换电脑、连接另一服务器或服务器主动更换密钥时需要重新填写。输入留空会复用原保存值；认证失败时应完整重新填写正确值。
5. 点击“加载模型”上传文本并加载；点击“翻译模型”会补齐上传和加载。设置参数后点击“开始仿真”；开始入口会补齐未完成的准备步骤。
6. 结果下载到客户端并核对本次模型 SHA-256、任务身份、参数和 CSV 校验值，可在原布局内查看、回放。网络中断按原有“重连并核对”流程处理，不重复启动远端任务。

## 4. 同一客户端在本机仿真

1. 本机安装并授权 Sysplorer，保存工作并关闭需要安装/更新插件的目标实例。
2. 启动客户端，在“连接设置”选择本机模式并连接；也可以直接点击加载、翻译或开始。首次显式操作才触发本机检查和配置，缺少配套插件时请求 UAC。
3. 安装检测读取常见安装目录和 Windows 安装记录。多个安装目录会显示选择窗口；自定义安装也可浏览选择其 `Bin64\mworks.exe`。选择后保存到 `%LOCALAPPDATA%\BatteryConsole\local-runtime.json`。后续连接检查使用保存的安装目录，不依赖开发工作树、私有宿主或盘符映射。
4. 自动检查未完成时不会启动宿主。配置成功后按需连接/启动所选 Sysplorer；普通本机模式不需要填写远程访问密钥。
5. 指定自定义安装或重新选择安装时，可在客户端目录执行以下命令，然后重启客户端：

   ```powershell
   powershell.exe -NoProfile -ExecutionPolicy Bypass -File '.\Setup-Local.ps1' -SysplorerHome 'D:\MWORKS\Sysplorer 2026a'
   ```

6. 本机插件默认只开放回环 UDP；已有远程服务器配置不会被本机配置流程关闭或重置。运行目录仍使用该安装已有 `Workspace`。
7. 没有 C 盘或需指定其他英文任务目录时，首次配置可给 `Setup-Local.ps1` 或 `Setup-Server.ps1` 增加 `-Workspace 'D:\BatteryJobs'`。已有 `remote.ini` 中的任务目录会优先保留；更换已有目录时先保存关闭宿主、备份并明确修改 `Workspace`，再执行配置并确认日常用户有写权限。

## 5. 修改模型文本及版本更新

模型文件必须是有效 UTF-8，最大 1 MiB，并保留固定的电池接口。每次任务准备读取一份文本快照，上传编号、接口版本、字节数和 SHA-256 随文本一起校验；UDP 每块最多 768 字节，TCP 每块最多 48 KiB。损坏、缺块或哈希错误均不会进入加载。未使用的上传在空闲 60 秒后清理。

准备后修改文件，必须重新翻译才能开始；运行中修改不会影响正在执行的任务。宿主空闲时插件可替换自己加载的旧模型；用户手工加载的同名 `BatterySim`，以及插件模型中的用户修改，会报告冲突，要求用户自己处理，程序不自动覆盖。旧插件会提示缺少上传能力，不能继续使用内置旧模型绕过检查。

只更新插件时：保存工作、关闭目标实例，用管理员 PowerShell 运行配套 `Update-Plugin.ps1 -SysplorerHome '实际安装目录'`。脚本备份旧 DLL、校验 SHA-256，并保留配置、端口、凭据和防火墙。客户端整包解压到新目录，关闭旧客户端后启动新包，保留正确的用户配置。不要把旧 DLL 与新客户端混用。

回退时先保存并停止任务、关闭目标 Sysplorer 和客户端，再从脚本输出的 `versions\旧哈希.dll` 备份恢复旧 DLL，配合原版本客户端；如果手工改过配置，从自己的备份恢复。回退过程中不要生成新密钥。生产更新前自行备份 `remote.ini`，不要将其加入发布包。

## 6. 网络及故障处理

- TCP 连不上：先在服务器检查监听，再核对实际 IP、端口和网络配置。公共网络默认不放行；应将可信局域网设为专用网络，或由管理员按实际网络策略配置窄范围规则。
- 跨子网客户端：默认 `LocalSubnet` 不覆盖它。首次配置可显式传 `-AllowedClientAddress '具体客户端IP或CIDR'`。重复配置保留现有规则；修改现有规则应由管理员核对程序路径、端口、Domain/Private 配置文件和允许源地址，不能简单放开所有网络。
- 改端口：保存关闭服务器，备份后修改现有 `remote.ini` 的 `Port`，重新运行服务器配置以建立对应规则；清理由管理员确认不再使用的旧端口规则，客户端同步修改端口。
- 认证失败：检查服务器原密钥，客户端完整重新填写，不要重装或反复生成新密钥。凭据用于授权访问该仿真宿主；协议认证不等于传输加密，跨不可信网络应使用受控 VPN。
- 求解器异常退出：核对本包插件已安装并重启宿主、Sysplorer 许可和编译器可用，再收集任务目录日志。插件负责为求解器准备宿主 `Bin64` 等依赖路径；不要随意复制 DLL 或修改系统 PATH。
- 有效结果保留；上传、加载或连接失败不应删除历史结果。退出客户端前先停止任务并等待停止确认，已知关闭窗口时的尽力停止仍有不稳定边界。

## 7. 发布包与测试的区别

正式包不携带开发机路径、凭据、缓存、私有宿主、SDK、日志或 `local-worktree.json`。用户配置、密钥和任务目录在目标电脑首次生成。开发用 `.local-sysplorer` 与盘符映射仅供工作树隔离验证，不属于部署依赖。

本轮开发测试不安装到当前系统 Sysplorer，不向现有虚拟机写入插件或防火墙。尚未提供的 2026b 隔离环境不能以模拟测试代替真实许可、加载和求解验收。
