## 验证中发现的问题

- 临时盘符用于让中文工作树中的隔离宿主获得英文编译路径。Windows 的进程查询返回底层路径，原本的字符串比较会拒绝同一个程序。已增加 Windows 文件身份比较，仍核对卷号与文件索引，不放宽到仅比较文件名；修复后本机回归通过。
- 离屏环境中用缺失宿主触发 QMessageBox 的布局夹具发生崩溃。布局测试改为连接已认证的本地测试服务；真实本机回归使用 Windows 平台插件。最终界面检查通过，没有把测试环境崩溃计入成功结果。
- 首次因路径别名导致的超时记录仍保留在 `logs/local/`；有效回归结论来自 `logs/local/final/`。
