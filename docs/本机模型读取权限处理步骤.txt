本机模型加载与仿真：当前处理步骤
更新时间：2026-11-08（北京时间）

历史说明：以下是 R3 外部模型阶段的排查与授权处理记录。R5 已改用客户端内置模型，并在不修改天喻策略的情况下完成普通双击本机验收。新版不需要按本文申请外部模型读取权限；请使用“可移植部署说明.md”和“内置模型交付测试报告.md”。

一、已确认的位置
1. 文件保护产品来自武汉天喻，模块产品名为 InteKEY。
2. 运行中的后台服务：TyEncryptService，显示名 TianYu Encrypt Client Service。
3. 服务程序：C:\Windows\SysWOW64\Tyfks.exe。
4. 加载模块：C:\Windows\System32\TyEnc64.dll、intefsctrl64.dll，签名均为武汉天喻。
5. 用户已找到右下角天喻/InteKEY 托盘图标；本机为单位管理设备，用户没有管理账号。

二、你现在要做什么
1. 先保存本机工作。不要改模型编码、卸载或停止天喻服务，也不用重新安装客户端。
2. 将下面“给单位 IT 的处理单”交给负责终端或文档安全的 IT 管理员。
3. 由管理员按单位批准流程执行应用授权，或对这一份模型执行批准的解密/提供明文副本。
4. 管理员处理后，关闭 Qt，再双击现有 R3 目录的 Start-Client.cmd，按第四部分验证。

管理员可选的批准方式：
A. 在单位实际版本的控制台配置该程序的受控应用/明文读取策略，并按该版本要求下发策略、重启应用。控制台地址与确切菜单需由单位管理员提供，当前未识别，不能从客户端服务路径推导。
B. 如果单位批准只解密这一份模型：由具备“直接解密”权限的人员操作。厂商 V11 手册提供的客户端入口为托盘“用户登录” -> “文件加解密” -> 添加这一份模型 -> 开始解密。菜单以本机实际版本为准；没有直接解密权限时走单位审批流程。不要尝试默认账号密码。
若策略使文件再次自动加密，应由管理员继续调整批准的使用方式，直到普通启动的 Qt 能读取模型；不要以改扩展名或其他进程代读绕过策略。

四、授权后怎么验证
1. 关闭 Qt。保留已经初始化好的 Sysplorer 2026a，也可按日常方式启动它。
2. 从现有 R3 目录双击 Start-Client.cmd。
3. 点击“连接设置” -> 选择“本机” -> “保存并连接”，等待“已连接”。
4. 点击“加载模型”。成功应显示已加载，不再出现 MODEL_UTF8_INVALID。
5. 保存充放电参数，点击“翻译模型”，等待准备完成，再点“开始仿真”。
6. 等待计算完成，到结果曲线页查看并点击回放；确认停止后再退出。
7. 若仍失败，保留本次新诊断路径及错误文字；不要发送账号密码或访问密钥。
