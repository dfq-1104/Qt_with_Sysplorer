# Sysplorer 2026b 已知插件加载阻塞修复

本文记录 2026-11-06 的 `9DE7…` 加载兼容补丁。2026-11-08 已更新为 `C7BEBE4A…` 任务接口补丁和修正后的服务器启动器，真实远程求解与完整/部分结果下载已通过。当前步骤见[最终部署与验收](远程模式最终部署与验收.md)，最新证据见[虚拟机远程模式验收](虚拟机远程模式验收.md)。不要用本文历史 DLL 或旧启动器覆盖已验证版本。

## 已确认原因

B 端 Sysplorer 版本为 26.8.0.2280，Qt 为 5.15.19。已安装插件 SHA-256 为 `9C187D822403DFEDAAC606EC97CBB06346027E846FA6C8B86D1DE80271E85F9A`，与原部署包一致。诊断确认宿主缺少该插件静态导入的两个符号：

```text
mw_develop.dll:
?CreatePlotWin@MwPlotWindowManager@@QEAAPEAVMwSimPlotWindow@@_NH0@Z

mw_global.dll:
?IsRunning@MwTaskManager@@QEAA_NXZ
```

这会阻止 Windows 加载插件，因而没有 TCP 39001 监听或远程状态文件。安装路径、端口和访问密钥不是本次加载失败的原因。

## 修复内容和边界

- 去掉上述两个静态导入，改为运行时检查已知的精确签名。
- 任务状态支持原 `IsRunning()` 和同名 `IsRunning() const` 两种明确签名。若均不存在，返回 `HOST_TASK_STATUS_API_UNSUPPORTED`，不把未知宿主当作空闲，不启动任务。
- 原生绘图仅在原精确接口可用时调用；否则保留真实结果导出和 Qt 查看/回放，并返回原生绘图不可用的说明。不猜测新绘图函数的参数或默认值。
- 诊断脚本增加任务状态候选导出和插件使用的 15 个精确动态符号检查，不执行这些函数，不读取密钥。
- 协议未改变，A 端不需要为本补丁更新 Qt 客户端。

新插件 SHA-256：

```text
9DE7BBE8C49BB7344409C08B0650EC3182EEF7D3105CFAD4C14F2FC208D3C509
```

这是对已确认加载阻塞的定向修复，**不等于已完成 2026b 全部 SDK ABI 或真实求解的现场验证**。

## B 端更新步骤

1. 保存工作，关闭 B 上的目标 Sysplorer 2026b。
2. 解压 `BatteryConsole-Server-CompatPatch.zip`。本次实际完整目录为 `C:\Users\dfq\Downloads\BatteryConsole-Server-CompatPatch`，确保该目录直接包含 DLL、`Update-ServerPlugin.ps1`、`patch-manifest.json` 和 `Diagnose-Server.ps1`。若解压到其他位置，命令使用实际路径。
3. 在管理员 PowerShell 中运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File 'C:\Users\dfq\Downloads\BatteryConsole-Server-CompatPatch\Update-ServerPlugin.ps1' -SysplorerHome 'C:\Program Files\MWORKS\Sysplorer 2026b'
```

4. 确认输出 `Updated plugin`、新 DLL 哈希以及配置/凭据保留提示。脚本会把原 DLL 备份到补丁目录；重复执行已安装补丁时不会再次替换。若安装的旧 DLL 不是已确认版本，脚本拒绝覆盖。
5. 使用原服务器包的启动脚本，保留之前的安装记录和配置：

```powershell

```

6. 等待主窗口完成初始化，再检查：


7. 用补丁中的新版诊断脚本复核实际宿主接口：


应先确认监听成功、`Plugin loaded: True`。`taskStatusSupported=True` 且没有 `MISSING_RUNTIME_EXPORTS` 是继续实测前的接口检查条件，不能替代真实加载、翻译和仿真验证。`nativePlotSupported=False` 可以接受，表示保留 Qt 曲线并跳过不匹配的原生自动绘图。

如果仍失败，回传检查输出或 `server-diagnostic.json`。不需要发送 `access-key.txt` 或完整 `remote.ini`。不要重新执行 `Install-Server.ps1`，以免无意更换密钥；本补丁不修改配置、访问凭据和防火墙。
