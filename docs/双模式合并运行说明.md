# 当前工作树统一客户端：本机与远程模式

**当前版本请先阅读《启动与连接纠错说明_20261108》**。38813A7F… EXE 已修正直接启动时的私有绑定和远程代理干扰；以该说明中的入口及复测为准。

启动和部署步骤见《两端部署操作手册_20261108》；本轮实测及未解决问题见《双模式测试报告_20261108_be10》。当前工作树为 be10，5f2f 与 570e 只作只读来源，不使用它们的运行绑定。

## 启动入口

- app/ui/run_local.bat：打开 Qt，本机连接、加载、翻译、开始时按需启动私有宿主。
- app/ui/run_remote.bat：预检指定服务器后打开同一客户端，当前目标 172.19.15.159:39001，失败不回退本机。
- app/ui/run_ui.bat：通用入口，保留保存模式。
- 私有运行目录中的 Start-Local.ps1 强制本机；Start-Client.ps1 保留保存模式；Start-Remote.ps1 接收 Address、Port、KeyFile。

现有布局和三个页签保持不变，启动不自动连接。任务空闲时在“连接设置”切换模式；本机四个入口按需启动宿主。

## 本机私有环境

活动客户端和宿主以 .local-sysplorer/state.json 为准，不复制其他工作树的 state.json 或盘符。入口验证二进制哈希，准备当前树的发现、任务、临时目录；英文别名仅复用属于本树的 T–Z 映射或空闲盘符。

两项生命周期能力和模型校验均保留，不允许放宽校验绕过旧插件。

私有宿主依赖已安装 Sysplorer 2026a 的库和许可，不是完整可搬移安装。Prepare-LocalWorktree.ps1 使用明确的 ClientDirectory 和 PluginDll 输入准备；已有不同版本时传入 NewGeneration，保留旧运行目录。不修改系统安装目录，不覆盖正在运行的 EXE/DLL。

## 远程环境

插件和客户端分别内置配套模型。客户端发送哈希、命令及参数；插件在服务器准备模型并求解。远端不需要 Qt 或手工预先打开模型。仅远程使用的独立客户端不需要安装 Sysplorer。

服务器通过配套 Start-Sysplorer.ps1 启动，使求解器继承安装目录 Bin64 和 Simulator/Bin64。本轮首次 START_FAILED 后，由用户用修复脚本重启，再完成真实远程求解与回放；未更换插件或凭据。

凭据通常保存一次后按当前 Windows 用户复用，启动仍需显式连接。认证失败应完整重填服务器现有密钥，不要重新执行首次安装来更换凭据。

## 测试边界

本轮本机主流程和真实远程求解、回放通过。隔离回归发现关闭运行中的客户端可能未及时停止服务器任务的边界问题，尚未稳定修复。先点击“停止”，确认终态后退出，不把关闭窗口当作可靠停止操作。

详细证据以当前测试报告为准。旧《双模式合并验证记录》为 5f2f 的历史验收，不替代 be10 本轮结果。
