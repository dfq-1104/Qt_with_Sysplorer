# 当前工作树统一客户端：本机与远程模式

当前目录为 `5f2f` 工作树。`570e` 只作为只读参考；新客户端与私有 Sysplorer 均绑定当前树，不依赖旧树的盘符或运行目录。

## 准备与启动

准备脚本 `tools/deployment/Prepare-LocalWorktree.ps1` 使用本机已安装的 Sysplorer 2026a 创建当前树的私有宿主，使用当前客户端和经过校验的本机插件。准备不会启动 Qt 或 Sysplorer，也不会修改系统安装目录。

**本次已经准备完成，当前电脑不需要再安装或复制DLL。** 请从上述工作树启动入口进入，不再使用系统旧插件对应的历史客户端副本。

- `app/ui/run_local.bat`：本机入口，只打开 Qt；连接、加载、翻译、开始时按需启动私有宿主。
- `app/ui/run_remote.bat`：远程入口，预检指定服务器后打开同一客户端；失败不会切回本机。当前默认 `172.19.15.159:39001`，凭据从当前树忽略目录的既有文件读取，不随包分发。
- `app/ui/run_ui.bat`：通用入口，保留用户保存的模式。
- 已生成运行目录内 `Start-Client.ps1` 保留保存模式，`Start-Local.ps1` 强制本机；`Start-Remote.ps1` 接收明确的 `-Address -Port -KeyFile`。

界面布局保持不变。在“连接设置”中切换本机或远程，保存并连接。只有任务空闲时允许切换；启动时不自动连接或启动宿主。当前 Windows 账号已保存的正确远程凭据不清除、不重新生成。

## 本机环境

私有宿主位于 `.local-sysplorer/host-*`，客户端位于 `dist/local-worktree/<代次>/BatteryConsole-Client-win64`，两者记录在 `.local-sysplorer/state.json`。启动入口验证其哈希，配置英文盘符别名和独立发现、任务、临时目录；所有实际数据留在当前树。不会连接系统旧插件或 570e 私有实例。

本机插件沿用 570e 已通过真实验证的 2026a DLL：`9C187D822403DFEDAAC606EC97CBB06346027E846FA6C8B86D1DE80271E85F9A`。客户端保留当前远程修复。模型 SHA-256 为 `e03bd3634004ca82bb190521c214ec5fae25713120db83caf016aeac8b7472cd`，两项生命周期能力及模型检查均保留。

英文盘符仅复用属于当前树的映射或空闲 T–Z 盘符，不覆盖其他目录的映射。程序使用期间不要手工移除该映射；清理工具遇到活动程序会拒绝清理。

运行包依赖本机已安装的 Sysplorer 2026a、库与许可，不是独立 Sysplorer 安装包；不能把含当前树绑定的运行目录直接搬到其他电脑。迁移时使用准备脚本重新生成，不复制旧 state.json 或盘符配置。

当前活动目录是 `dist/local-worktree/ed83cd7a2286/BatteryConsole-Client-win64`。其中 `Start-Client.ps1` 为通用入口，`Start-Local.ps1` 为本机入口，切换模式仍在同一窗口完成。直接双击裸EXE不会准备工作树环境，请使用启动脚本。

ZIP是当前工作树的运行包归档，含客户端和绑定，不含整套Sysplorer。解压后的脚本会定位当前树的活动代次，不能把ZIP当作其他电脑的直接安装包。

若需重新准备，在当前树根目录运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tools\deployment\Prepare-LocalWorktree.ps1
```

若准备新构建且原代次已存在，显式追加 `-NewGeneration`。旧目录保留，新状态指向新代次；不要手动覆盖正在运行的EXE或DLL。`-EnvironmentOnly` 只准备路径绑定并返回上下文，不启动程序，也不改变调用终端环境。

## 失败处理

能力、模型、文件或绑定不匹配会明确失败，不跳过校验。先检查本机入口是否来自当前树，再核对目标路径、模型和插件。不要为本机问题重装远端服务器或更换远程密钥。

本次不会关闭或替换用户原窗口。旧运行包保留，需用户保存工作后自行切换入口。升级时使用新代次目录，不原地覆盖正在使用的 EXE 或 DLL。
