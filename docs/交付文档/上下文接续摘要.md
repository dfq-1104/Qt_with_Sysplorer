# 上下文接续摘要

更新：2026-11-04。用途：后续接续；不替代源码和验收证据。

## 当前完成状态

本轮正式 UDP 改造已构建、管理员部署并通过本机固定电池模型验收。当前链路为 Qt Widgets 客户端 → loopback UDP → 可见 Sysplorer 内的 BatteryUdpControl 插件 → 宿主现有模型管理和仿真控制对象。没有独立 SDK helper 或常驻 Python 桥接参与正式路径，编译器和求解器可有子进程。

## 行为基线

- 应用参数：只校验保存，并更新 SOC、剩余容量及待仿真预览。
- 仿真：按模型指纹、方向、电压、电流、起始 SOC 比较最近一次完整成功内存缓存；命中则从头回放，不创建任务或重复打开原生结果。
- 未命中：发现或启动本机 Sysplorer，插件真实加载、设参回读、翻译、求解；Qt 轮询样本并实时绘图。
- 实时任务暂停/继续控制实际求解；缓存回放暂停/继续控制播放器。
- 主动停止：保留当前有效部分曲线与数值、任务编号、时间范围，标识部分结果；继续不可用。再次仿真重新查缓存，未命中从初始设置重算。
- 部分结果独立选择，不覆盖完整缓存；失败保留完整缓存。缓存和部分结果仅在客户端当前进程中维护，未实现退出后自动恢复。
- 零电流真实计算 120 秒；倍速映射 SDK 减速因子 1/speed。

- app/ui/src/main_window.*：任务编排、完整缓存与部分结果展示；plot_widget.* 实时绘图。
- tools/sysplorer_udp_plugin/control_plugin.*：宿主插件、SDK 调用及原生曲线。
- 正式入口：app/ui/runtime/battery_console_ui.exe。
