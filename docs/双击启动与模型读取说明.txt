内置模型客户端：20261108-embedded-model-r5

1. 完整解压客户端 ZIP 到新目录。
2. 普通双击 Start-Client.cmd。启动先检查 EXE 内置模型，随后显示原界面。
3. 点击连接设置，选择本机或远程，保存并连接。
4. 加载模型 -> 保存参数 -> 翻译模型 -> 开始仿真 -> 查看结果和回放。
启动本身不会连接或启动 Sysplorer；本机按需启动，远程失败不切换本机。

本机：电脑须已安装并授权 Sysplorer 2026a/2026b。首次连接按提示准备插件。
仅远程：客户端电脑不要求安装 Sysplorer；填写服务器实际 IPv4、端口和原凭据。
已部署且已通过检查的服务器无需为本次模型来源变化重新安装或更换密钥。

模型已编入 battery_console_ui.exe。:/models/BatterySim.mo 是 Qt 资源地址，
不是磁盘路径。正式客户端不读取外部 .mo，也不接受 BATTERY_MODEL_FILE 覆盖。
不需要寻找 models 文件夹；更新模型需重新构建并发布客户端。
插件仍会将收到的模型写入宿主任务目录后加载和求解。
内置不等于模型加密或防提取；模型随客户端分发应遵循所属单位授权。

没有修改天喻策略。普通双击是否完成本机与远程验收，以验证记录.md 为准。
Check-Model.cmd 只检查内置模型，不启动或连接宿主。
退出前先停止任务并等待确认；窗口关闭时停止任务仍有已知不稳定情况。
详细的两端安装、连接、更新和回退步骤见 部署说明.md。
