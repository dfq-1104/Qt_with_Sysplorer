# 电池客户端 UDP 版运行说明

先构建部署 tools/sysplorer_udp_plugin，然后运行 app/ui/build.cmd 和 app/ui/deploy.ps1，启动 runtime/battery_console_ui.exe。隔离联调包位于 runtime_udp。

新运行包只部署界面和 Qt 依赖。旧 sdk_probe.exe 和 sysplorer_view.py 不再参与正式运行。

## 操作

| 操作 | 行为 |
|---|---|
| 应用参数 | 校验、保存、更新预览，不启动任务 |
| 仿真命中缓存 | 回放当前进程最近完整成功结果 |
| 仿真未命中 | UDP 连接/启动 Sysplorer，真实计算并实时绘图 |
| 暂停/继续 | 新任务控制求解，缓存回放控制播放器 |
| 停止新任务 | 保留部分结果及有效时间范围，禁用继续 |
| 结果选择 | 分别查看完整成功结果与各次已停止部分结果 |
| 停止后再次仿真 | 重新判断缓存，未命中则从设置的初始状态计算 |

部分结果不覆盖完整缓存。两者仅属于当前客户端进程，关闭后不自动恢复为缓存。零电流执行真实 120 秒静置仿真，其他时长按容量估算并限制在 120–20000 秒。

任务目录通常位于 Temp/BatteryConsoleUDP/<任务编号>，包含客户端、插件日志、状态及结果文件。错误显示在窗口上方。未发现插件时检查部署并重启宿主；模型不一致时重新构建两端资源；宿主忙碌时等待，不接管其他任务。Program Files 写入需管理员权限，仅更改脚本执行策略无效。

正式协议与开发验收记录见 docs/UDP任务协议.md 和 docs/UDP正式接入开发记录.md。历史六篇交付文档描述此前 helper 架构。
