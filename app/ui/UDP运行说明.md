# 电池客户端 UDP 版运行说明

先构建 tools/sysplorer_udp_plugin 和 app/ui，准备隔离宿主，再通过 app/ui/deploy.ps1 配置运行包。使用下述一键入口启动。

新运行包只部署界面和 Qt 依赖。旧 sdk_probe.exe 和 sysplorer_view.py 不再参与正式运行。

## 操作

| 操作 | 行为 |
|---|---|
| 界面打开 | 后台连接或启动 Sysplorer，检查插件能力与模型版本；不加载、不翻译、不求解。失败警告不关闭主窗口 |
| 保存参数 | 只校验并保存客户端设置；相同数值不使准备实例失效。翻译和开始均读取当前输入，不要求先保存 |
| 加载模型 | 只加载并确认模型；不写参、不翻译、不求解 |
| 翻译模型 | 自动加载或复用模型，然后校验、写参、逐项回读、翻译；成功后等待用户开始 |
| 开始仿真 | 自动完成必要的加载和翻译，再请求启动；有效准备实例可复用。失败即停止后续步骤 |
| 暂停仿真 / 继续仿真 | 只控制本客户端的真实求解；请求待确认时禁用相关按钮 |
| 停止仿真 | 等待停止、导出和核验，保留真实部分结果及停止时间，不归零 |
| 回放所选结果 | 只播放结果下拉框中选定的有效结果，不调用宿主或创建新任务 |
| 暂停回放 / 继续回放 / 停止回放 | 只控制本地播放器，与仿真按钮、倍速、时间和状态独立 |
| 状态信息 / 分阶段日志 | 分别展开或收起，默认收起并保存选择；错误摘要仍直接显示，收起不停止记录日志 |
| 运行中调参 | 保留第三个页签及原有功能；以模型采样回读确认生效 |

本工作树的按钮细化版使用 `run_ui.bat` 或 `run_button_details.bat`，指向 `runtime_buttons`。运行包中 `sysplorer.ini` 已配置本轮专用宿主 `%TEMP%/BB0cf2`，没有替换安装目录插件或其他工作树的运行包。显式 `SYSPLORER_HOME` 可以覆盖配置，覆盖时必须使用配套新插件。

重新生成运行包：`deploy.ps1 -RuntimeDirectory <本目录>/runtime_buttons -SysplorerHome <专用宿主目录>`。插件与客户端必须一起更新，握手要求 `modelLifecycle=true`。后台等待统一使用 `Host/TimeoutMs`（毫秒，默认 90000，可用环境变量 `BATTERY_HOST_TIMEOUT_MS` 覆盖）；本轮运行包与测试使用 180000，以容纳首次初始化。

在线调参版使用 `run_runtime_tuning.bat`，通过本目录 `runtime_tuning/sysplorer.ini` 选择隔离的真实 Sysplorer 副本。合并验证使用 `%TEMP%/BatteryConsoleMergeValidation`；安装目录可能被其他测试更新，不作为本轮验证入口。
旧入口 `run_runtime_tuning.bat` 仍启动该隔离包，不依赖安装目录中的旧插件。需要重建隔离宿主时运行 `tools/sysplorer_udp_plugin/prepare_isolated_host.ps1`，更新 Qt 包用 `deploy.ps1 -RuntimeDirectory <本目录>/runtime_tuning -SysplorerHome <隔离宿主目录>`。
部署会校验隔离插件与工作树编译产物一致，并保存可执行程序旁的 `sysplorer.ini`；直接双击该包内的 exe 也能选择相同宿主。显式 `SYSPLORER_HOME` 环境变量仍可覆盖该配置。
已有实例模型版本不符时会跳过并尝试其他实例；新启动宿主仍不符时明确报告宿主路径及两端模型哈希，保留版本保护。

运行期模式：0 静置、1 恒流充电、2 恒流放电、3 恒压/限流充电。恒压目标与截止电压分开。
运行中提交会短暂停算、批量暂存输入并继续，时间和 SOC 不重置；已暂停时提交保持暂停，点击继续后确认。
界面显示首次模型采样确认的仿真时刻。带动态修改的结果保留轨迹与 result.json 中的输入历史，不复用为静态参数缓存。


运行、暂停、停止确认及准备期间禁止回放。完整结果与停止结果分别保留；停止结果在下拉框中自动选中；回放始终使用当前所选结果，失败任务不替换有效结果。结果仅属于当前客户端进程，关闭后不自动恢复。零电流执行真实 120 秒静置仿真，其他时长按容量估算并限制在 120–20000 秒。

Qt 界面可独立显示、回放已有结果；新计算依赖 Sysplorer。新版界面与插件需配套部署；替换插件前须保存工作并退出已加载旧插件的 Sysplorer。旧插件会被新客户端明确拒绝；加载、翻译和启动不会混为同一个协议命令。
任务目录通常位于 Temp/BatteryConsoleUDP/<任务编号>，包含客户端、插件日志、状态及结果文件。错误显示在窗口上方。未发现插件时检查部署并重启宿主；模型不一致时重新构建两端资源；宿主忙碌时等待，不接管其他任务。Program Files 写入需管理员权限，仅更改脚本执行策略无效。
