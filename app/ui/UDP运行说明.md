# 电池客户端 UDP 版运行说明

先构建部署 tools/sysplorer_udp_plugin，然后运行 app/ui/build.cmd 和 app/ui/deploy.ps1，启动 runtime/battery_console_ui.exe。隔离联调包位于 runtime_udp。

新运行包只部署界面和 Qt 依赖。旧 sdk_probe.exe 和 sysplorer_view.py 不再参与正式运行。

## 操作

| 操作 | 行为 |
|---|---|
| 应用参数 | 校验、保存、更新预览，不启动任务 |
| 仿真命中缓存 | 回放当前进程最近完整成功结果 |
| 仿真未命中 | UDP 连接/启动 Sysplorer，真实计算并实时绘图 |
| 暂停/继续 | 新任务控制求解，缓存回放控制播放器 |
| 停止新任务 | 保留部分结果及有效时间范围，禁用继续 |
| 结果选择 | 分别查看完整成功结果与各次已停止部分结果 |
| 停止后再次仿真 | 重新判断缓存，未命中则从设置的初始状态计算 |
| 运行中调参 | 第三个页签修改电流指令、恒压目标、模式、上下截止电压、电流上限；在后续模型采样确认生效 |

当前工作树在线调参版请使用 `run_runtime_tuning.bat`，使用 `%TEMP%/BatteryConsoleRuntime` 中的真实 Sysplorer 副本和本工作树 `runtime_tuning` 中的 Qt 包。主目录尚未合并本工作树的修改；安装目录可能被其他测试更新，不作为本轮验证入口。
两个工作树入口 `run_ui.bat` 和 `run_runtime_tuning.bat` 均启动该隔离包，不依赖安装目录中的旧插件。需要重建隔离宿主时运行 `tools/sysplorer_udp_plugin/prepare_isolated_host.ps1`，更新 Qt 包用 `deploy.ps1 -RuntimeDirectory <本目录>/runtime_tuning -SysplorerHome <隔离宿主目录>`。
部署会校验隔离插件与工作树编译产物一致，并保存可执行程序旁的 `sysplorer.ini`；直接双击该包内的 exe 也能选择相同宿主。显式 `SYSPLORER_HOME` 环境变量仍可覆盖该配置。
已有实例模型版本不符时会跳过并尝试其他实例；新启动宿主仍不符时明确报告宿主路径及两端模型哈希，保留版本保护。

运行期模式：0 静置、1 恒流充电、2 恒流放电、3 恒压/限流充电。恒压目标与截止电压分开。
运行中提交会短暂停算、批量暂存输入并继续，时间和 SOC 不重置；已暂停时提交保持暂停，点击继续后确认。
界面显示首次模型采样确认的仿真时刻。带动态修改的结果保留轨迹与 result.json 中的输入历史，不复用为静态参数缓存。

部分结果不覆盖完整缓存。两者仅属于当前客户端进程，关闭后不自动恢复为缓存。零电流执行真实 120 秒静置仿真，其他时长按容量估算并限制在 120–20000 秒。

任务目录通常位于 Temp/BatteryConsoleUDP/<任务编号>，包含客户端、插件日志、状态及结果文件。错误显示在窗口上方。未发现插件时检查隔离宿主准备结果；模型不一致时重新构建两端资源。客户端跳过被其他任务占用的宿主，必要时启动独立宿主，保留原任务；新宿主使用独立工作目录，避免并发模型编译相互覆盖。本轮只修改当前工作树，不更新安装目录或主目录。

正式协议与开发验收记录见 docs/UDP任务协议.md 和 docs/UDP正式接入开发记录.md。历史六篇交付文档描述此前 helper 架构。
